API Geoapify Geolocalização aplicada aos ecopontos.

A Geoapify é o serviço externo utilizado para transformar endereços de ecopontos em coordenadas geográficas.

Informação enviada: endereço textual do ecoponto.

Informações recebidas: latitude e longitude.

As coordenadas permitem posicionar cada ecoponto no mapa e calcular a distância aproximada até o usuário.

A Geoapify também fornece o estilo cartográfico exibido pelo MapLibre na tela de pontos de coleta.

API REST integrada Dados dos ecopontos Informações consumidas pelo aplicativo.

A lista de ecopontos é carregada pela API REST do SheetDB. Caso um endereço ainda não tenha coordenadas, o aplicativo consulta a Geoapify e armazena o resultado localmente para evitar chamadas repetidas.
